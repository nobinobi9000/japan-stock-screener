プライバシーポリシー

制定: 2025-02-18  ／  最終更新: 2025-02-26
概要
日本株スクリーニングサービス（以下「本サービス」）は、利用者の個人情報の 取扱いについて以下のとおりプライバシーポリシーを定めます。 本サービスを利用することにより、本ポリシーに同意したものとみなされます。

1. 収集する情報

本サービスでは、以下の情報を収集します：

情報の種類 収集方法 収集目的
Discord アカウント情報
（ユーザーID・ユーザー名）		 Discord サーバー参加時 通知サービスの提供・プラン管理
決済情報
（Stripe 経由。カード情報は当方に渡らない）		 有料プラン申込時 決済処理・請求管理
アクセスログ
（IPアドレス・閲覧ページ・日時）		 サービス利用時に自動収集 セキュリティ確保・サービス改善

2. 情報の利用目的

収集した個人情報は、以下の目的でのみ利用します：

  • スクリーニング結果の Discord 通知配信
  • 有料プランの管理・請求処理
  • サービスの品質改善・新機能の開発
  • お問い合わせへの対応
  • 規約違反行為の調査・対応
  • 法令に基づく対応

3. 情報の第三者提供

当方は、以下の場合を除き、個人情報を第三者に提供しません：

  • 利用者の同意がある場合
  • 法令に基づく場合（裁判所・行政機関からの開示請求等）
  • 人の生命・身体または財産の保護のために必要がある場合

利用している外部サービス

本サービスは、以下の外部サービスを利用しています。各サービスのプライバシーポリシーが適用されます：

Discord
スクリーニング結果の通知配信に利用。Discord の利用規約・プライバシーポリシーが適用されます。
Stripe
有料プランの決済処理に利用。クレジットカード情報は Stripe が直接管理し、当方には渡りません。
GitHub Pages
本サービスの Web ホスティングに利用。GitHub のプライバシーポリシーが適用されます。

4. 情報の保管・管理

当方は、個人情報への不正アクセス・紛失・破損・改ざん・漏洩等を防止するため、 適切な安全管理措置を講じます。 不要になった個人情報は、適切な方法で削除します。

5. Cookie 等の使用

本サービスでは、サービス改善のために以下の技術を使用する場合があります：

  • Cookie（セッション管理・設定保存）
  • アクセス解析ツール（将来的に導入予定）

Cookie はブラウザの設定から無効化できますが、一部機能が利用できなくなる場合があります。

6. 個人情報の開示・訂正・削除

利用者は、当方に対して以下を請求できます：

  • 当方が保有する個人情報の開示
  • 個人情報の訂正・追加・削除
  • 個人情報の利用停止・消去

請求は、Discord サーバー内のサポートチャンネル、 または GitHub Issues よりお願いします。 本人確認の上、合理的な期間内に対応します。

7. プライバシーポリシーの変更

当方は、必要に応じて本ポリシーを変更することがあります。 変更後のポリシーは、本サービス上に掲載された時点で効力を生じます。 重要な変更がある場合は、Discord サーバーにてお知らせします。

8. お問い合わせ

個人情報の取扱いに関するお問い合わせは、以下よりお願いします：

  • Discord サーバー内のサポートチャンネル
  • GitHub Issues（japan-stock-screener リポジトリ）
